# Security Policy

## Supported Versions

Gradeway is currently pre-release (work-in-progress). There are no stable/versioned releases yet, so security fixes are
only made against the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately using one of the following:

- **Email:** [social@gradienttim.dev](mailto:social@gradienttim.dev)
- **Discord:** message a maintainer directly on the [Discord server](https://discord.gg/f35EemU4jS)

Please include as much detail as possible: affected module/version, steps to reproduce, and potential impact. You should
receive an acknowledgment within a few days. Once a fix is available, the vulnerability will be disclosed and credited
(if desired) alongside the fix.
